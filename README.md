# WORD COUNTER

## OVERVIEW
**WORD COUNTER** IS A JAVA-BASED GUI APPLICATION THAT COUNTS THE NUMBER OF CHARACTERS, WORDS, AND SENTENCES IN A GIVEN TEXT. THE APPLICATION SUPPORTS MULTIPLE FEATURES LIKE UNDO/REDO, FILE OPERATIONS (OPEN/SAVE), AND A DARK MODE TOGGLE FOR A PERSONALIZED USER EXPERIENCE.

## FEATURES
- **CHARACTER COUNT**: DISPLAYS THE TOTAL NUMBER OF CHARACTERS IN THE ENTERED TEXT.
- **WORD COUNT**: DISPLAYS THE TOTAL NUMBER OF WORDS IN THE ENTERED TEXT.
- **SENTENCE COUNT**: DISPLAYS THE TOTAL NUMBER OF SENTENCES IN THE ENTERED TEXT.
- **UNDO/REDO**: ALLOWS USERS TO UNDO AND REDO TEXT CHANGES.
- **FIND & REPLACE**: USERS CAN FIND AND REPLACE SPECIFIC TEXT WITHIN THE CONTENT.
- **DARK MODE**: A TOGGLE FOR SWITCHING BETWEEN LIGHT AND DARK THEMES FOR THE APPLICATION.
- **CLEAR TEXT**: CLEARS ALL THE CONTENT IN THE TEXT AREA.
- **FILE OPERATIONS**: OPEN AND SAVE TEXT FILES DIRECTLY FROM THE APPLICATION.

## TECHNOLOGIES USED
- JAVA SWING (GUI)
- UNDOMANAGER FOR UNDO/REDO FUNCTIONALITY
- JAVA I/O FOR FILE OPERATIONS (OPEN/SAVE)
